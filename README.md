# 7rulnik 7rulnik

## How do I install these formulae?

`brew install 7rulnik/7rulnik/<formula>`

Or `brew tap 7rulnik/7rulnik` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "7rulnik/7rulnik"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
